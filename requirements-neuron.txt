# App-layer Python deps for FLUX.1-Kontext-dev training on AWS Trainium (Neuron).
#
# IMPORTANT: this file deliberately does NOT list packages the Neuron stack owns.
# setup_neuron.sh installs optimum-neuron[neuronx,training] FIRST, which pins a
# mutually-compatible set: torch (Neuron build), torch-neuronx, neuronx-cc,
# libneuronxla, torch_xla, transformers, accelerate, diffusers, peft, tokenizers,
# huggingface_hub, safetensors, numpy. Re-listing any of those (especially with a
# hard ==pin) would let pip overwrite the Neuron-pinned versions and pull a CUDA
# torch — the exact failure to avoid. They are installed under a constraints lock.
#
# Removed vs the repo's GPU setup:
#   - bitsandbytes  (CUDA-only 8-bit Adam; XLA falls back to torch.optim.AdamW)
#   - flash-attn    (CUDA-only; FLUX uses plain SDPA, compiled by neuronx-cc)

# --- Pure-app deps not part of the base Neuron stack ---
Pillow
tqdm
datasets
sentencepiece          # required by the T5 tokenizer (T5TokenizerFast)

# --- logging ---
wandb
