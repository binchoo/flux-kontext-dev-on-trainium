# App-layer Python deps for FLUX.1-Kontext-dev training on AWS Trainium (Neuron).
#
# IMPORTANT: this file does NOT list packages the Neuron stack OWNS (torch,
# torch-neuronx, neuronx-cc, libneuronxla, torch_xla, transformers, accelerate,
# tokenizers, huggingface_hub, safetensors, numpy). optimum-neuron[neuronx,training]
# installs and version-pins those FIRST. Re-listing them here (esp. with a ==pin)
# would let pip overwrite the Neuron-pinned versions and pull a CUDA torch.
#
# Everything below IS installed here, but UNDER a pip constraints lock (see
# setup_neuron.sh step 5) that freezes the Neuron stack — so resolving these deps
# can pull legit transitive packages yet can NEVER change torch/transformers/etc.
#
# Removed vs the repo's GPU setup:
#   - bitsandbytes  (CUDA-only 8-bit Adam; XLA falls back to torch.optim.AdamW)
#   - flash-attn    (CUDA-only; FLUX uses plain SDPA, compiled by neuronx-cc)
